See it on a TV

Recorded on a TCL Google TV. The questions were sent as text through adb, the same path the setup guide uses for tests.

Every TV is different

TV makers add their own memory cleaners, start blockers and key handling. So tvask is not an app you install and forget. You set it up together with your own AI coding agent. It checks your TV, installs tvask, adapts to what it finds, and tests the result with you.

Turn on Developer options and USB debugging on the TV, then give your agent this prompt:

Read AGENTS.md in https://github.com/urtuba/tvask and set up tvask on my TV
at <tv-ip>. Show me each command before you run it.

An agent with adb access has shell rights on your TV. Read what it runs before you allow it.

What you need

  • Android TV or Google TV with Android 11 or newer, with the Google app for Android TV.
  • A voice remote paired over Bluetooth. An IR-only remote sends no audio.
  • A computer with adb, and an AI coding agent that can run shell commands.
  • An API key for an OpenAI compatible chat model, DeepSeek by default, and a Brave Search API key.

What it can do

Answer and search

Answers in the language you speak, and searches the web or reads a page when it needs to.

Open and find

Opens apps and searches inside YouTube, YouTube Music, Prime Video and the browser.

Cards

Weather, site options you pick with OK, match scores, open apps and system status.

The TV itself

Lists and closes open apps, checks whether a site works, shows memory and storage.

Conversation and memory

Follow-up questions work for five minutes. Small notes about you stay on the TV.

Context, not pixels

Knows what is playing and what the app in front shows, if you allow it. Never uses screenshots.

Settings on the TV

Reading speed, the wait after a pause, the browser, the screen language and the memory size. Change them with the remote.

Your TV needs a change? Fork it.

Most TVs need only settings and adb commands. If yours needs code changes, fork the repository and keep them in your fork. Search links, the panel and the model's tools each live in one file. Send back fixes that help every TV as a pull request, and tell us about your TV in an issue.

Privacy

  • Your voice goes to Google, through Google's speech recognizer on the TV.
  • The recognized text, your app list and your memory notes go to the chat model provider you chose. The TV context goes only when you ask about it, and you can turn it off.
  • Text from web pages and the screen is treated as data. While it is in a turn, tvask cannot close apps or change its memory.
  • Web searches go to Brave. Weather places go to Open-Meteo.
  • API keys stay in the app's private storage. Only adb can set them.
